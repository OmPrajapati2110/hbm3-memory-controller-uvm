FCFS serves strictly in order, so every row change costs a full precharge and activate. FR-FCFS serves ready row hits first, which is fast, but client 3's writes wait almost 2,000 cycles: the read stream keeps the data bus busy, so it never turns around to write. Once a request has waited 256 cycles, aging reserves its bank and its bus direction, so it finishes in a few hundred cycles while the other banks keep working. Latency is in controller cycles, from acceptance to response.
